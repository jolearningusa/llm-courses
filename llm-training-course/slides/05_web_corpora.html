Problem: the web is big, raw and mostly not text

  • A Common Crawl snapshot holds billions of pages in many languages; most of each page is navigation, boilerplate and repeated content.
  • Chinchilla-style budgets (architecture deck 06) need trillions of tokens, more than curated sources such as Wikipedia, books and papers can supply.
  • Two answers: filter the web hard (CCNet, RefinedWeb), or mix the web with curated sources (The Pile, Dolma). Every pipeline since has the same stages.

CCNet: dedup, language ID, perplexity buckets

  • Dedup paragraphs: normalize (lowercase, digits to 0, no punctuation or accents), hash with SHA-1, drop repeats.
  • Language ID: a fastText classifier over 176 languages; keep pages scoring above 0.5. Dedup runs first, which helped low-resource languages.
  • Quality: a 5-gram language model trained on Wikipedia scores each paragraph's perplexity; each language is split into head, middle and tail thirds.
  • One February 2019 snapshot: 1.5 billion documents in 174 languages; English alone 532B tokens. About 9 hours on 5,000 CPU cores.
  • BERT-base trained on the filtered crawl beat one trained on Wikipedia on XNLI by 3.3 points on average, and by 7 points for Urdu.

RefinedWeb: web data alone is enough

  • Claim: properly filtered and deduplicated web data alone can train models that match ones trained on curated corpora.
  • Pipeline (MDR): URL blocklist of 4.6M domains; trafilatura text extraction; language ID ≥ 0.65; Gopher-style repetition and document rules; line-wise corrections; MinHash dedup; exact dedup of spans over 50 tokens; URL dedup across dumps.
  • Language ID alone removes about half the documents; after the rules about 23% of Common Crawl documents remain; the full pipeline removes nearly 90%.
  • MinHash with 9,000 hashes over 5-grams in 20 buckets; the Pile's 10 hashes deduplicated less and trained worse models.
  • About 5 trillion tokens of English; 600B released.
Penedo et al. 2023 (RefinedWeb), arXiv:2306.01116 §3, Table 2, Fig. 2 · bibliography

Training impact and afterlife

  • Filtering is the main lever. RefinedWeb moved the default from curated sources to filtered web; Dolma and FineWeb (deck 06) kept that and published the pipeline.
  • Measure with small models. Dolma, RefinedWeb and FineWeb all judge a pipeline change by training a 1B-class model on it, the method decks 06 and 07 build on.
  • Openness and licensing. The Pile documented every source; Dolma released data and tools; later corpora track licenses per source.
  • OLMo-1B, trained on Dolma, averaged 60.3 on eight tasks against TinyLlama's 59.4; the OLMo family is covered in architecture deck 33.
