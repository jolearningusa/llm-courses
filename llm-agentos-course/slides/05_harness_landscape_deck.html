The open harness landscape, October 2026

Eleven open-source harnesses compared on popularity and on the AgentOS components they actually ship: personal agent runtimes, composable substrates, coding agents and a research kernel. Every star count was read from the project's GitHub page on 2026-10-26.

TaxonomyFour kinds of harness, four different bets

Personal agent runtimes

A long-running process you talk to from chat apps, with memory, skills and a scheduler.

OpenClaw (reach: one gateway, many channels), Hermes Agent (self-improvement: skills and memory it writes itself), Goose (a desktop and CLI agent built on MCP extensions).

Composable substrates and agent servers

A kernel you build an agent product on.

DeepSeek Harness ("everything is a plugin" on the Cordis runtime), Letta (stateful agents served over an API, with editable memory blocks).

Coding agents

The loop, tools and sandbox tuned for a repository.

OpenCode, Codex CLI, Cline, Aider (terminal and IDE) and OpenHands (agents in Docker sandboxes, local or cloud).

Research kernels

An OS layer under other agent frameworks.

AIOS: a kernel that turns agent requests into syscalls and schedules the LLM, memory, storage and tools shared by many concurrent agents.

Project READMEs on github.com (links on the next slides); AIOS paper, arXiv 2403.16971.

MethodChecking the numbers: what the summaries got wrong

A search summary from 2026-10-26, checked

  • DeepSeek Harness "~260k": the repo shows 252.0k. "Fastest to 200k in 15 days": no source; SandBase reports about 18.5k stars at the August launch and 242,936 on Oct 4.
  • Aider "MIT": the repo is Apache-2.0.
  • OpenHands "69k–93k": 91.8k. Cline "61k+": 67.6k. AIOS "6.5k, 925 forks": 6.4k, 908.
  • "Global #N" ranks, "8M+ installs", "OpenClaw 2.0 Skill Workshop": not found in any primary source.

Rules we used in this deck

  • Read stars from the repo page, write the date next to them, and expect them to drift in weeks.
  • Prefer the README and the docs over blogs; quote a blog only for what it measured.
  • Follow redirects: sst/opencode → anomalyco/opencode, block/goose → aaif-goose/goose.
  • Mark what you could not confirm ("—") instead of filling the cell.
