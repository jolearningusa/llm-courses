比较十一个开源 harness 的热度，以及它们实际提供的 AgentOS 组件：个人智能体运行时、可组合底座、编码智能体和一个研究型内核。 所有 star 数均于 2026-10-26 从项目的 GitHub 页面读取。

分类四类 harness，四种不同的押注

个人智能体运行时

一个长期运行的进程，通过聊天应用与之对话，带有记忆、技能和调度器。

OpenClaw（覆盖面：一个网关，多个渠道）、Hermes Agent（自我改进：自己编写技能和记忆）、Goose（基于 MCP 扩展构建的桌面与 CLI 智能体）。

可组合底座与智能体服务器

用来构建智能体产品的内核。

DeepSeek Harness（基于 Cordis 运行时的“一切皆插件”）、Letta（通过 API 提供有状态智能体，带可编辑的记忆块）。

编码智能体

针对代码仓库调优的循环、工具和沙箱。

OpenCode、Codex CLI、Cline、Aider（终端和 IDE）以及 OpenHands（Docker 沙箱中的智能体，本地或云端）。

研究型内核

位于其他智能体框架之下的操作系统层。

AIOS：一个把智能体请求转换为系统调用的内核，并调度众多并发智能体共享的 LLM、内存、存储和工具。

github.com 上各项目的 README（链接见后续幻灯片）；AIOS 论文，arXiv 2403.16971。

方法核查数字：摘要错在哪里

2026-10-26 的一份搜索摘要，经核查

  • DeepSeek Harness “~260k”：仓库显示 252.0k。“15 天内最快达到 200k”：无来源；SandBase 报告 8 月发布时约 18.5k star，10 月 4 日为 242,936。
  • Aider “MIT”：该仓库是 Apache-2.0。
  • OpenHands “69k–93k”：91.8k。Cline “61k+”：67.6k。AIOS “6.5k，925 forks”：6.4k，908。
  • “全球第 N” 排名、“8M+ 安装量”、“OpenClaw 2.0 Skill Workshop”：在任何一手来源中均未找到。

本课件采用的规则

  • 从仓库页面读取 star 数，在旁边写明日期，并预期它在几周内就会变化。
  • 优先采用 README 和文档而非博客；仅在博客有实际测量时才引用。
  • 跟随重定向：sst/opencode → anomalyco/opencode，block/goose → aaif-goose/goose。
  • 对无法确认的内容标记“—”，而不是随意填写单元格。
