Ein Sprachmodell liest Text als eine Folge von Tokens. Bevor das Modell etwas sieht, zerlegt ein Tokenizer den Text in Stücke und ordnet jedem Stück eine ganze Zahl zu. Häufige Wörter werden zu einem einzigen Token, seltene Wörter werden aus kleineren Stücken zusammengesetzt. Das Modell sieht nie direkt Buchstaben, sondern nur die Zahlen, die der Tokenizer erzeugt hat. Deshalb entscheidet der Tokenizer, wie lang ein Dokument ist, wie viel Text in das Kontextfenster passt und wie viel jede Anfrage kostet. Zusammengesetzte Wörter wie Kontextfensterlänge oder Abwasserbehandlungsanlage zeigen, warum ein festes Wortvokabular nicht ausreicht. Ein Tokenizer, der für eine Sprache gut ist, kann für eine andere schlecht sein. Byte-basierte Tokenizer beginnen mit den 256 möglichen Bytewerten, sodass jede Zeichenkette kodiert werden kann und das Dekodieren immer den ursprünglichen Text zurückgibt.
