An image is worth 16×16 words

Dosovitskiy et al. (Google), 2020. Cut an image into patches, treat each patch as a token, and run an unmodified Transformer encoder. With enough pre-training data, it matches or beats the best convolutional networks for less compute.

Problem: attention did not scale to pixels

  • By 2020 Transformers ruled NLP, but vision still used CNNs; attention over every pixel is quadratic in the pixel count.
  • Earlier work combined attention with convolutions or used special sparse patterns that were hard to run fast on accelerators.
  • Question: can a standard Transformer, with as few changes as possible, work on images if the "words" are patches?

Change: patches become tokens

A 224 × 224 image with 16 × 16 patches gives 196 tokens. The model name gives the patch size: ViT-L/16 uses 16 × 16 patches. 2D-aware position embeddings gave no significant gain over learned 1D ones (5-shot linear ImageNet: none 0.614, 1D 0.642, 2D 0.640).

Evidence: what attention learns

  • CNNs have locality and translation equivariance built in. In ViT only the MLP is local; attention is global from layer 1.
  • Some heads in the lowest layers already attend across most of the image; others stay local, behaving like early convolutions.
  • The mean attention distance grows with depth for all heads.
  • Learned position embeddings end up encoding 2D distance: nearby patches get similar embeddings, with row and column structure.
Dosovitskiy et al. 2020, arXiv:2010.11929 §4.5, Fig. 7 · bibliography

Modeling impact

  • One architecture for every modality. Once images are token sequences, the text machinery (attention, scaling laws, KV caches) applies to them.
  • Patch size is a compute knob. Halving the patch quadruples the tokens; DiT uses the same knob for diffusion (deck 39).
  • The vision tower of VLMs. CLIP's and SigLIP's image encoders are ViTs (deck 35); LLaVA, Gemma 3 and Llama 4 feed ViT patch features to a language model (decks 29, 32, 36).
  • Priors trade against data. The ViT result is the vision version of the scaling lesson: with enough data, generic models win.
