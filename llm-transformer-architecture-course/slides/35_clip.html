CLIP: learning vision from language

Radford et al. (OpenAI), 2021. Train an image encoder and a text encoder so that matching image-caption pairs get similar embeddings. 400M web pairs are enough to classify images zero-shot, by writing the class names as text.

Problem: fixed label sets do not transfer

  • Vision models were trained on a fixed set of labels (ImageNet's 1,000 classes). Every new task needs new labeled data and a new head.
  • The web has hundreds of millions of images with free-form text next to them.
  • GPT-2 and GPT-3 (decks 02, 05) showed that natural language supervision at scale gives zero-shot transfer in text. Can the same work for images?

Change: contrastive, not predictive

  • First try: predict the caption word by word with a 63M-parameter Transformer. It learned ImageNet zero-shot 3× slower than predicting a bag of words.
  • Second step: only decide which caption goes with which image. The contrastive objective was another 4× more efficient.
  • Exact captions are hard to predict and mostly irrelevant; the pairing carries the signal that matters.
Radford et al. 2021, arXiv:2103.00020 §2.3, Fig. 2 · bibliography
3 / 8

Change: the symmetric contrastive loss

For a batch of N pairs, maximize the N matching (diagonal) similarities and minimize the N² − N others: cross-entropy over each row (image → text) plus over each column (text → image). τ is learned, initialized to 0.07 and clipped so logits are scaled by at most 100. Batch size 32,768.

Zero-shot classification

  • The best model reaches 76.2% top-1 on ImageNet zero-shot, matching the original ResNet-50 without any of its 1.28M labeled examples.
  • The prompt template alone adds 1.3%; ensembling 80 prompts adds another 3.5% on ImageNet.
  • Zero-shot CLIP closes up to 75% of the gap between ImageNet accuracy and accuracy under distribution shift. Fine-tuning on ImageNet raises ImageNet accuracy by 9.2% but slightly lowers the shifted-set average.
Radford et al. 2021, arXiv:2103.00020 §3.1.3–3.1.4, §3.3 · bibliography

Modeling impact

  • Language becomes the label space. Any concept that can be written down can be classified, retrieved or used as a condition.
  • The standard vision tower. LLaVA uses CLIP ViT-L/14 (deck 36); SigLIP, a sigmoid-loss successor, is Gemma 3's encoder (deck 32).
  • Text conditioning for generation. CLIP text embeddings steer diffusion models (deck 38).
  • Batch size is part of the method. Each example's negatives are the rest of the batch, which is why the batch is 32,768.
