Problem: the compute-optimal model is not the cheapest to serve

  • Chinchilla (deck 06) asks which model is best for a fixed training budget. For a model that will answer millions of prompts, the inference budget matters more.
  • LLaMA's target: the best performance at a given inference cost, which means a smaller model trained on more tokens. "The performance of a 7B model continues to improve even after 1T tokens."
  • The strongest models of early 2023 (GPT-3, PaLM, Chinchilla) used private data and were not released. LLaMA uses only publicly available data.

Evidence: small models catch large ones

  • LLaMA-13B beats GPT-3 (175B) on most benchmarks while being more than 10× smaller; it runs on a single GPU.
  • LLaMA-65B is competitive with Chinchilla-70B and PaLM-540B.
  • Training cost of the 65B model: about 380 tokens/s/GPU on 2048 A100 80GB GPUs, so 1.4T tokens take about 21 days.
  • Training loss was still falling for every size when training stopped.

Llama 2-Chat: the post-training recipe in the open

  • Quality over quantity: a few tens of thousands of vendor-written SFT examples beat millions of third-party ones.
  • Two reward models, because helpfulness and safety pull in different directions.
  • Ghost Attention (GAtt) synthesizes multi-turn data so an instruction from the first turn ("always answer in French") is still followed at turn 20.

Modeling impact

  • Over-training became the default. Training a small model far past compute-optimal (deck 06) is now normal for any model that will be served at scale; Llama 3 8B saw 15T tokens (deck 29).
  • A shared block. RMSNorm, SwiGLU, RoPE and (from Llama 2) GQA became the default decoder; Mistral, Qwen, Yi and many others started from it.
  • Open weights changed research. Fine-tuning (Alpaca, Vicuna), quantization (llama.cpp, GPTQ) and interpretability work could now study a strong model directly.
  • Post-training documented. Llama 2 is one of the first detailed public accounts of SFT, reward modeling and RLHF at scale.

Afterlife

  • Llama 3 kept the block and scaled data and vocabulary; Llama 4 moved to MoE and early fusion (deck 29).
  • Code Llama and Llama Guard were built on Llama 2.
  • The 2/3 · 4d SwiGLU width and the "pre-norm RMSNorm + RoPE + SwiGLU" recipe appear in almost every config file in Part VII.
