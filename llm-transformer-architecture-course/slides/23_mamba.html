Problem: attention cost grows with the sequence

  • Attention compares every token with every earlier one: quadratic compute in training and a KV cache that grows with every generated token (Part III).
  • Subquadratic alternatives (linear attention, gated convolutions, structured state space models such as S4) had not matched attention on language.
  • Gu and Dao name the weakness: they cannot do content-based reasoning. A time-invariant model applies the same dynamics to every token, so it can solve plain copying but fails at selective copying, which requires deciding from content what to keep.

Change: selection

  • S4 starts from h′(t) = Ah(t) + Bx(t), y = Ch(t), discretized with a step size Δ (zero-order hold: Ā = exp(ΔA)). A, B, C and Δ are fixed across time, so the layer is a convolution and can be trained in parallel.
  • Mamba makes B, C and Δ functions of the current input: B = LinearN(x), C = LinearN(x), Δ = softplus(Linear(x)).
  • A large Δ resets the state toward the current token; a small Δ keeps the past and ignores the current token. The model learns, per token, what to remember.
  • Cost: the convolution shortcut is gone, so the layer must be computed as a recurrence (a scan).

Change: a hardware-aware scan and a simple block

  • Scan. Kernel fusion, a parallel scan and recomputation in the backward pass: the expanded state lives in on-chip SRAM and is never written to HBM (the FlashAttention idea, deck 14). With state size N = 16, faster than FlashAttention-2 beyond 2K tokens.
  • Block. One repeated block merges the earlier H3 layer with a gated MLP: expand by E = 2, short convolution, SiLU, selective SSM, multiplicative gate, project back. No attention, no separate MLP.

Mamba evidence

  • Synthetic tasks. Solves selective copying and induction heads; trained at length 256, the induction-head solution generalizes to about 1M tokens.
  • Language. The first attention-free model to match the strong Transformer++ recipe (RoPE, SwiGLU, RMSNorm) in scaling curves. Mamba-3B outperforms Transformers of the same size and matches Transformers twice its size.
  • Inference. About 5× the generation throughput of a Transformer of similar size, since there is no KV cache to read.
  • Other modalities. DNA (better with context up to 1M) and audio (SC09 FID 0.94 against 1.99 for SaShiMi).

Mamba-2: state space duality

  • Restrict A further, from diagonal to a scalar times the identity. Then the SSM's sequence transformation equals a form of masked linear attention: the same model has a recurrent (linear-time) form and a quadratic, attention-like form, connected through semiseparable matrices.
  • The SSD algorithm computes blocks in the quadratic form (matrix multiplies on tensor cores) and passes states between blocks recurrently: 2–8× faster than Mamba's scan, and 6× faster than FlashAttention-2 at 16K tokens.
  • That allows states 8× larger than Mamba's or more, and heads of dimension 64 or 128 as in Transformers. A, B, C and X come from one projection at the block start; an extra norm before the output projection.

Mamba-2 evidence and the limits

  • Under Chinchilla-style scaling, Mamba-2 Pareto-dominates Mamba and Transformer++ in perplexity against wall-clock time. A 2.7B Mamba-2 trained on 300B Pile tokens beats Mamba-2.8B, Pythia-2.8B and Pythia-6.9B.
  • The limit is recall. A fixed state must compress the whole past, so a task that needs an exact earlier token, such as copying a long passage or recalling one of many key-value pairs, eventually exceeds what the state can hold; attention keeps every token.
  • Jamba's ablation (deck 24) shows the practical symptom: a pure Mamba model failed to follow in-context answer formats that the attention and hybrid models followed. Gated DeltaNet (deck 25) attacks the same weakness from inside the recurrence.

Modeling impact and afterlife

  • Constant memory per token. Generation cost no longer grows with context: no KV cache, only a state per layer.
  • Attention and recurrence are two views of one family. SSD made it routine to design a layer by choosing its state update and then derive a parallel training algorithm.
  • Hybrids won. The main production use is a few attention layers among many Mamba or linear-attention layers: Jamba (deck 24), and Qwen3-Next with Gated DeltaNet (deck 25).
  • Lab idea for a critique: write the selective scan as a Python loop and as the quadratic SSD form, and check they agree.
