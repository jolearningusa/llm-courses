Background: linear attention as a memory matrix

St = St−1 + vtktᵀ , ot = St qt

  • Drop the softmax from attention and the sum over past tokens becomes a fixed-size matrix S that each token writes a key-value association into. Constant memory, like Mamba (deck 23).
  • The problem: S only accumulates. Old associations are never removed, so retrieval degrades as the sequence grows and the matrix fills.

Two fixes, each half a solution

LayerUpdateGood atWeak at
Mamba-2St = αt St−1 + vtktᵀForgetting fast (α → 0 clears the state)Decays every association by the same factor; cannot target one
DeltaNetSt = St−1(I − βtktktᵀ) + βtvtktᵀOverwriting the value stored at key kt (the delta rule)No fast way to clear the whole memory

The delta rule first reads what S stores for kt, removes it, and writes the new value: one association is replaced, the rest are untouched.

Change: the gated delta rule

St = St−1 ( αt ( I − βt kt ktᵀ ) ) + βt vt ktᵀ

  • αt ∈ (0, 1), data-dependent: α → 0 wipes the memory, α → 1 gives the pure delta rule.
  • βt: how strongly this token overwrites its key.
  • Training is parallel in chunks: the WY (UT) representation of products of Householder-like matrices, extended with the gating terms.

Qwen3-Next: the architecture in production

  • Qwen3-Next-80B-A3B: 3 Gated DeltaNet layers for every standard attention layer.
  • Attention layers add an output gate, use 256-dimensional heads and apply RoPE to only the first 25% of each head's dimensions.
  • MoE: 512 experts, 10 routed and 1 shared active per token, so 80B total and about 3B active parameters.

Qwen3-Next: what it reports

  • Training cost: 9.3% of Qwen3-32B's compute for the base model.
  • Throughput: more than 10× Qwen3-32B for prefill and decoding beyond 32K tokens; decoding nearly 4× faster at 4K.
  • Context: 262,144 tokens natively; validated with YaRN (deck 10) to 1M.
  • Stability: zero-centered RMSNorm with weight decay on the norm weights; router weights normalized at initialization.
  • Multi-token prediction (deck 27) is built in for speculative decoding.

These are a vendor's blog numbers, not a peer-reviewed paper; treat them as claims to check against the released weights.

Modeling impact and afterlife

  • Memory with an edit operation. The delta rule gives a recurrent layer a way to replace one stored association, which is what in-context retrieval needs.
  • Hybrid ratios moved. Jamba used 1 attention layer in 8 (deck 24); Qwen3-Next uses 1 in 4, with a stronger recurrent layer.
  • Everything at once. Qwen3-Next stacks a linear-attention hybrid, very sparse MoE (deck 22) and MTP (deck 27): the design space of Part VI in one model.
  • The Qwen3 family deck (deck 30) compares Qwen3-Next with the dense and MoE Qwen3 models.
