Problem: the most quality per byte on one device

  • Gemma targets models that run on a laptop, a single GPU or a phone. At those sizes, memory for weights and the KV cache decides what fits.
  • Gemma 2 notes that training a small model longer improves it only logarithmically with the data, and replaces the one-hot next-token target with a richer one: a teacher's distribution.
  • Gemma 3 adds two more needs: long context (128K) and images, both without blowing up memory.

Gemma 2: local and global layers, soft-capping

  • Layers alternate a 4,096-token sliding window (deck 15) and global attention over 8,192 tokens.
  • Logit soft-capping: logits pass through cap · tanh(x / cap), with cap 50 in attention and 30 on the final layer.
  • RMSNorm on both the input and the output of each sub-layer (pre- and post-norm), and GQA with 2 query heads per KV head.

Gemma 3: 5 local per global, 128K, vision

  • Five local layers per global layer, and the window shrinks to 1,024 tokens. Only global layers keep the full context in the KV cache.
  • In the report's ablation (a 2B model at 32K context), KV-cache memory overhead falls from 60% with global layers only to under 15% with one global per three local layers and a 1,024 window.
  • QK-norm replaces Gemma 2's soft-capping. Global layers raise the RoPE base from 10K to 1M for 128K context (32K for 1B); local layers keep 10K.
  • Vision: a frozen 400M SigLIP encoder turns an 896 × 896 image into 256 soft tokens; Pan & Scan, at inference only, splits other aspect ratios into crops. The 1B model is text only.

Modeling impact

  • Local attention as KV-cache compression. Gemma 3 cuts the cache by making most layers local; gpt-oss alternates banded and dense layers in the same spirit (deck 33).
  • Logit control moves to QK-norm. Gemma 3 drops soft-capping for QK-norm, which Qwen3 also adopts (deck 30): both keep attention logits from growing.
  • Distillation is the small-model recipe. Gemma 2 and 3, Qwen3 and Llama 4 (Behemoth as teacher) all train small models from a larger one.
  • Vocabulary size is a trade-off. 256K tokens help multilingual text but cost embedding parameters, a large share for 1B–2B models.
