问题：固定的标签集无法迁移

  • 视觉模型在固定的标签集（ImageNet 的 1,000 个类别）上训练。每个新任务都需要新的标注数据和新的分类头。
  • 网络上有数亿张图像，旁边配有自由形式的文本。
  • GPT-2 和 GPT-3（讲义 02、05）表明，大规模自然语言监督能在文本上带来零样本迁移。同样的方法能用于图像吗？

改动：对比式而非预测式

  • 第一次尝试：用一个 63M 参数的 Transformer 逐词预测标题。它学习 ImageNet 零样本能力的速度比预测词袋慢 3 倍。
  • 第二步：只判断哪个标题配哪张图像。对比目标的效率又提高了 4 倍。
  • 精确的标题难以预测，而且大多无关紧要；配对关系才承载着重要的信号。

改动：对称对比损失

对一个含 N 对的 batch，最大化 N 个匹配（对角线）相似度，最小化其余 N² − N 个：对每一行（图像 → 文本）和每一列（文本 → 图像）分别求交叉熵。τ 是可学习的，初始化为 0.07，并加以截断，使 logit 最多放大 100 倍。batch 大小 32,768。

零样本分类

  • 最好的模型在 ImageNet 零样本上达到 76.2% top-1，与原始 ResNet-50 持平，而没有用它的 128 万个标注样本中的任何一个。
  • 仅提示模板就带来 1.3% 的提升；在 ImageNet 上集成 80 个提示又提升 3.5%。
  • 零样本 CLIP 把 ImageNet 准确率与分布偏移下准确率之间的差距缩小了最多 75%。在 ImageNet 上微调使 ImageNet 准确率提高 9.2%，但略微降低了偏移数据集上的平均准确率。

对建模的影响

  • 语言成为标签空间。任何能写下来的概念都可以用于分类、检索或作为条件。
  • 标准的视觉塔。LLaVA 使用 CLIP ViT-L/14（讲义 36）；采用 sigmoid 损失的后继者 SigLIP 是 Gemma 3 的编码器（讲义 32）。
  • 为生成提供文本条件。CLIP 文本嵌入引导扩散模型（讲义 38）。
  • batch 大小是方法的一部分。每个样本的负例就是 batch 中的其余样本，所以 batch 取 32,768。
