背景：把线性注意力看作记忆矩阵

St = St−1 + vtktᵀ , ot = St qt

  • 去掉注意力中的 softmax，对过去 token 的求和就变成一个固定大小的矩阵 S，每个 token 往里写入一条键值关联。内存恒定，与 Mamba（讲义 23）一样。
  • 问题：S 只会累加。旧关联从不被移除，所以随着序列增长、矩阵被填满，检索能力下降。
Yang, Kautz and Hatamizadeh 2024, arXiv:2412.06464 §2.1 · 参考文献

两种修补，各解决一半

层更新擅长不擅长
Mamba-2St = αt St−1 + vtktᵀ快速遗忘（α → 0 清空状态）所有关联按同一因子衰减；无法针对某一条
DeltaNetSt = St−1(I − βtktktᵀ) + βtvtktᵀ覆写存储在键 kt 处的值（delta 规则）没有快速清空整个记忆的方法

delta 规则先读出 S 为 kt 存储的内容，将其移除，再写入新值：只替换一条关联，其余不受影响。

改动：门控 delta 规则

St = St−1 ( αt ( I − βt kt ktᵀ ) ) + βt vt ktᵀ

  • αt ∈ (0, 1)，依赖于数据：α → 0 清空记忆，α → 1 得到纯 delta 规则。
  • βt：该 token 覆写其键的强度。
  • 训练按块并行：使用类 Householder 矩阵乘积的 WY（UT）表示，并扩展以包含门控项。

Qwen3-Next：投入生产的架构

  • Qwen3-Next-80B-A3B：每 3 个 Gated DeltaNet 层配 1 个标准注意力层。
  • 注意力层增加输出门控，使用 256 维的头，并且只对每个头前 25% 的维度应用 RoPE。
  • MoE：512 个专家，每个 token 激活 10 个路由专家和 1 个共享专家，因此总参数 80B、激活约 3B。

Qwen3-Next：报告的结果

  • 训练成本：基座模型的计算量为 Qwen3-32B 的 9.3%。
  • 吞吐量：超过 32K token 时，预填充和解码都比 Qwen3-32B 快 10 倍以上；4K 时解码快近 4 倍。
  • 上下文：原生 262,144 token；用 YaRN（讲义 10）验证到 1M。
  • 稳定性：零中心 RMSNorm，并对归一化权重施加权重衰减；路由器权重在初始化时归一化。
  • 内置多 token 预测（讲义 27），用于投机解码。

这些是厂商博客中的数字，不是同行评审论文；应把它们当作需要对照已发布权重来核验的说法。

对建模的影响与后续

  • 带编辑操作的记忆。delta 规则让循环层能够替换一条已存储的关联，这正是上下文检索所需要的。
  • 混合比例变化。Jamba 八层中用 1 层注意力（讲义 24）；Qwen3-Next 四层中用 1 层，循环层也更强。
  • 集大成。Qwen3-Next 叠加了线性注意力混合、非常稀疏的 MoE（讲义 22）和 MTP（讲义 27）：一个模型涵盖了第六部分的设计空间。
  • Qwen3 系列讲义（讲义 30）将 Qwen3-Next 与稠密和 MoE 版 Qwen3 模型进行比较。
