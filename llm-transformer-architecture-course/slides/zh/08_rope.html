问题：绝对位置还是相对位置？

  • 绝对嵌入（讲义 01 的正弦编码，GPT 和 BERT 的可学习编码）加在输入上。而注意力通常需要的是相对信息：“左边第二个词”。
  • 相对方案（Shaw 等，讲义 04 中 T5 的偏置）在注意力内部加项。它们有效，但改变了注意力的计算，也不适用于线性注意力变体。
  • 可学习的绝对位置表还固定了最大长度。
  • 目标：一种作用于 q 和 k 的编码，使 qm·kn 只是内容和 m − n 的函数。

改动：旋转每一对维度

f(x, m) = RΘ,m W x ; qmᵀ kn = xᵀ Wqᵀ RΘ,n−m Wk xn

  • 把 q 和 k 的 d 个维度分成 d/2 对。第 i 对旋转角度 m·θi，θi = 10000−2(i−1)/d：与 2017 年正弦编码的频率相同。
  • 先旋转 m、再做旋转 n 的逆，等于旋转 n − m，所以点积只看到偏移。
  • 在每一层作用于查询和键，不作用于值，也不作用于输入嵌入。

实现与性质

RoPE(x)2i = x2i cos mθi − x2i+1 sin mθi ; RoPE(x)2i+1 = x2i sin mθi + x2i+1 cos mθi

  • 用预先计算的 cos 和 sin 表逐元素计算：没有额外参数，计算量可以忽略。
  • 论文声称的性质：没有固定的最大长度；点积上界随距离长程衰减；与线性注意力兼容，因为旋转保持范数。
  • 高频维度对转得快，编码精细的局部顺序；低频维度对转得慢，编码粗略的位置。讲义 10 通过区别对待两端来扩展上下文。

论文中的证据

  • WMT14 英→德：27.5 BLEU，Transformer 基线为 27.3。
  • BERT 式预训练：RoFormer 的掩码 LM 损失比 BERT 收敛更快。
  • CAIL2019-SCM（长篇中文法律文书）：512 token 下 68.29%，BERT 为 67.77%；RoFormer 使用 1,024 token 时为 69.79%。
  • 作者坦承他们无法完整解释为什么收敛更快。它被广泛采用，更多是因为简单和相对位置这一性质，而不是这些数字。

建模影响

  • 零代价的相对位置。没有要学习的表，没有偏置项，也不向残差流添加任何东西。
  • KV 缓存存的是旋转后的键。每个键按自己的位置旋转一次后缓存；新的查询按它们自己的位置旋转。MLA（讲义 16）在压缩键时必须绕开这一点。
  • 上下文长度变成了频率问题。超出训练长度的位置会在最慢的维度对上产生模型从未见过的旋转角度。提高底数 θ（Llama 3：500,000）或缩放位置（讲义 10）是模型达到 128K 的方法。
