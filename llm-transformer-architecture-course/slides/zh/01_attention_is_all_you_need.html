问题：循环结构是串行的

  • 2017 年最强的翻译模型是带注意力的 RNN 或 LSTM 编码器-解码器。每一步都要等上一步的隐状态，所以即使在训练时，n 个 token 的句子也需要 n 个串行步骤。
  • 两个相距很远的词之间的信息要经过中间的每一个状态。长程依赖很难学到。
  • 卷积模型（ByteNet、ConvS2S）可以并行，但远距离位置之间的路径长度仍随距离增长。
  • 目标：训练可以在各位置间并行，并且任意两个位置之间只隔一步的模型。

改动 1：缩放点积注意力

Attention(Q, K, V) = softmax(Q Kᵀ / √dk) V

  • 每个查询给所有键打分；softmax 权重对值做加权混合。所有位置在一次矩阵乘法中算完。
  • 为什么除以 √dk：dk 很大时点积的数值变大，把 softmax 推进梯度极小的区域。
  • 掩码在 softmax 之前把不允许的分数设为 −∞。解码器屏蔽未来位置，使训练保持自回归。
Vaswani et al. 2017, arXiv:1706.03762 §3.2.1, §3.2.3 · 参考文献

改动 2：多个头并行

headi = Attention(QWiQ, KWiK, VWiV) ; MultiHead = Concat(head1..h) WO

  • base 模型：h = 8 个头，每个 dk = dv = dmodel/h = 64。总代价接近一个全宽度的头。
  • 不同的头可以同时关注不同的位置和关系，一个取平均的头做不到。
  • 每个头都有自己的 K 和 V。MQA（讲义 12）、GQA（13）和 MLA（16）正是重新审视这个选择来缩小 KV 缓存。

完整模型

  • 每个子层被包装为 LayerNorm(x + Sublayer(x))：先残差连接，再归一化（post-LN）。
  • FFN(x) = max(0, xW₁ + b₁)W₂ + b₂，逐位置应用，dff = 2048 = 4 × dmodel。
  • 交叉注意力的查询来自解码器，键和值来自编码器的记忆。

改动 3：没有循环结构时如何表示位置

PE(pos, 2i) = sin(pos / 100002i/d) ; PE(pos, 2i+1) = cos(pos / 100002i/d)

  • 仅靠注意力不感知顺序：打乱输入就会以同样方式打乱输出。必须注入位置信息。
  • 正弦编码加到 token 嵌入上。对固定的偏移 k，PE(pos + k) 是 PE(pos) 的线性函数，作者希望注意力能借此利用相对位置。
  • 可学习的位置嵌入给出几乎相同的结果（表 3，E 行）。保留正弦编码是因为它也许能外推到更长的序列。
  • 讲义 08 展示 RoPE 如何把同样的频率变成对查询和键的旋转。

为什么用注意力：论文自己的比较

层类型每层代价串行操作数最大路径长度
自注意力O(n² · d)O(1)O(1)
循环O(n · d²)O(n)O(n)
卷积O(k · n · d²)O(1)O(logk n)
受限自注意力O(r · n · d)O(1)O(n / r)

当 n < d 时自注意力比循环便宜，这对 2017 年的句子长度成立。上下文增长到 128K token 后，n² 项正是讲义 14、15、23 和 26 要解决的问题。

建模影响

  • 并行训练。去掉循环结构使在多得多的数据上训练变得可行。讲义 05 和 06 中的每个缩放结果都依赖于此。
  • 一个块，多种用法。编码器栈和解码器栈分成了不同的家族：仅编码器的 BERT（讲义 03）、仅解码器的 GPT（02）和编码器-解码器的 T5（04）。
  • 新的内存代价。推理时解码器为每个过去的 token 和每一层保存 K 和 V：即 KV 缓存。它每个 token 的大小为 2 × 层数 × 头数 × dk，这推动了第三部分。
  • 二次项。注意力的计算量和分数矩阵的内存按 n² 增长，只有当上下文变长后才成为问题。
