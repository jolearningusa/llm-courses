LLaMA 与 Llama 2

Touvron 等（Meta），2023 年 2 月和 7 月。一个由三项已有选择（前置 RMSNorm、SwiGLU、RoPE）组装成的仅解码器 Transformer，在公开数据上远超 Chinchilla 最优点进行训练，并公开发布。Llama 2 增加了 GQA、更长的上下文和对话模型。

问题：计算最优的模型并不是部署最便宜的模型

  • Chinchilla（讲义 06）问的是在固定训练预算下哪个模型最好。对一个要回答数百万个提示的模型来说，推理预算更重要。
  • LLaMA 的目标：在给定推理成本下获得最佳性能，也就是用更多 token 训练一个更小的模型。"The performance of a 7B model continues to improve even after 1T tokens."（7B 模型的性能在 1T token 之后仍在提升。）
  • 2023 年初最强的模型（GPT-3、PaLM、Chinchilla）使用私有数据，且未公开发布。LLaMA 只使用公开可得的数据。

证据：小模型追上大模型

  • LLaMA-13B 在大多数基准上胜过 GPT-3（175B），而规模不到其十分之一；它可以在单块 GPU 上运行。
  • LLaMA-65B 可与 Chinchilla-70B 和 PaLM-540B 竞争。
  • 65B 模型的训练成本：在 2048 块 A100 80GB GPU 上约 380 token/秒/GPU，因此 1.4T token 约需 21 天。
  • 训练停止时，每个规模的训练损失仍在下降。

Llama 2-Chat：公开的后训练配方

  • 质量胜过数量：几万条由供应商撰写的 SFT 样本胜过数百万条第三方样本。
  • 两个奖励模型，因为有用性和安全性的方向不同。
  • Ghost Attention（GAtt）合成多轮数据，使第一轮的指令（"always answer in French"，始终用法语回答）到第 20 轮仍被遵循。

对建模的影响

  • 过度训练成为默认做法。把小模型训练到远超计算最优点（讲义 06），如今对任何要大规模部署的模型都很正常；Llama 3 8B 训练了 15T token（讲义 29）。
  • 共享的模块。RMSNorm、SwiGLU、RoPE 以及（从 Llama 2 起的）GQA 成为默认的解码器；Mistral、Qwen、Yi 等许多模型都以此为起点。
  • 开放权重改变了研究。微调（Alpaca、Vicuna）、量化（llama.cpp、GPTQ）和可解释性研究从此可以直接研究一个强模型。
  • 后训练有了文档。Llama 2 是最早详细公开大规模 SFT、奖励建模和 RLHF 的报告之一。

后续影响

  • Llama 3 保留模块，扩大了数据和词表；Llama 4 转向 MoE 和早期融合（讲义 29）。
