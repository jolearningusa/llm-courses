LLM Transformer 架构

今天的语言、视觉、扩散和语音模型背后的架构是怎样一步步建立起来的，一次读一篇论文：每个改动为什么被提出，它对模型做了什么。

这门课面向谁

  • 使用 LLM、并希望读懂模型卡、config.json 或技术报告中每个选择含义的工程师和学生。

每份论文讲义的结构

  1. 问题。论文写作时什么失败了或代价太高。
  2. 改动。架构上的想法，以及定义它的公式或图。
  3. 证据。论文测了什么、在什么规模、与哪个基线比较。
  4. 建模影响。对质量、参数量、FLOPs、KV 内存的影响，以及它让什么成为可能。
  5. 后续。哪些后来的模型保留、修改或放弃了它，并对照其配置核实。

直接续作（GPT-1 和 GPT-2、Mamba 和 Mamba-2）共用一份讲义。算子和推理服务留给计算课程。

十个只需 CPU 的实验

  • L0 从 config.json 算出参数量和 KV 字节数
  • L1 一个块，三种结构：编码器、解码器、编码器-解码器
  • L2 字节级 BPE 与不同语言的 token 成本
  • L3 正弦位置编码、RoPE、ALiBi 与位置插值
  • L4 手工实现聊天模板和打包掩码
  • L5 带 KV 缓存的 MHA、MQA、GQA 和 MLA
  • L6 在字符级模型上比较块的变体
  • L7 带负载均衡损失的 top-k MoE
  • L8 ViT 图块与 CLIP 式对比损失
  • L9 音频的残差向量量化

每个实验都把输出与参考实现或手算值对照检查。

本课程的边界

  • 本课：模型计算什么，以及它为什么这样设计。
  • 高效 LLM 计算系统：如何跑得快，包括注意力算子、KV 分页、MoE 执行、量化和推理服务。
  • LLM AgentOS：智能体往上下文窗口里放什么，以及如何跨轮次管理记忆。
  • 训练方法（数据、RLHF、面向推理的 RL）只在能解释某个架构选择时出现，例如 DeepSeek-R1 沿用 V3 的架构。

如何使用这些讲义

  • 每次课一份论文讲义，然后做对应的实验。课前阅读每页幻灯片上注明的论文章节。
  • 幻灯片引用数字时会给出表格或章节号。请到原处核对，如有公开配置也一并核对。
  • 考核：实验 50%，两篇论文评析 20%，毕业项目 30%。毕业项目要在给定的参数、KV 内存和模态预算下设计一个模型，并用论文为每个选择辩护。
