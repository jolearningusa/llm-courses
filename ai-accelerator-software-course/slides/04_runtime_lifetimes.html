Completion, observation and reclamation

Completion does not itself free the command’s outstanding slot or pins. Reap checks observed terminal state, then releases resources once.

Double completion and double reap must fail visibly.

A timeout is an observation

A deadline can expire because work is queued, slow, hung or its notification was lost. These need different recovery decisions.

The application request ending does not prove the device request ended.

Cleanup and admission failures

Allocation limit, queue full, invalid packet and device FAULT are separate errors. Check that rejected submissions leave no pins or slots.

Preserve error identity rather than hiding every failure behind a retry.
