Copy and add-one are exact byte operations

Opcode 1 copies length bytes. Opcode 2 adds one modulo 256; 255 becomes 0. Destination tail remains unchanged.

No matrix kernel, real DMA bus or numerical inference performance is simulated.

Ordering and visibility are separate ideas

The model writes output atomically before publishing completion. Real platforms need their documented memory/barrier/coherency rules.

A Python event ordering does not establish an ISA memory-order proof.

Lost interrupt versus incomplete work

With drop_irq, the device can finish while the host wait times out. Polling discovers completion; reap then releases pins.

Separate device done, host observed and buffer reclaimable.

A queue-wide deadline is different

Two FIFO commands wait for two service intervals plus admission/start progression. Do not reuse a one-command timeout without checking the queue.

Model latency and watchdog values are ticks, not milliseconds.
