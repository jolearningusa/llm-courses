Image identity and compatibility

tutorial-fw-v1 and ABI 1 are model identifiers. Unsupported boot records a fault and requires reset before retry.

A name/hash records identity; it does not establish secure boot, trusted signing or physical compatibility.

The functional reset atomically stops old work, releases pins and advances generation. This is an explicit model assumption.

A real target must prove old DMA/compute access is stopped before reclaim. Tagging completions alone cannot stop physical writes.

Capture the recovery evidence

  • Initial state/image, active command and buffer owners.
  • Fault trigger, last known completion and timeout boundary.
  • Quiesce/reset sequence, new generation and known-good boot.
  • Stale event rejection and a successful fresh command.
