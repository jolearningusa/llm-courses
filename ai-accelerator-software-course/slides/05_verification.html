Seeded state exercising

Randomly choose supported/invalid API actions, record rejections and check independent invariants after each action.

Reproduce the seed and minimize a failure. Rejection count is not coverage; this is not coverage-guided fuzzing.

The bounded ownership model

State = command phase + buffer-live flag. Explore enabled submit/start/cancel/complete/release transitions.

Safe policy forbids release while outstanding. The intentionally unsafe policy has a submit → release counterexample.
