Handles are not DMA addresses

Linux distinguishes CPU virtual, physical and DMA/bus addresses. Mapping and coherency rules depend on the device/platform.

The teaching model uses integer buffer handles and coherent byte arrays only.

5 / 10

Validate before consuming resources

  • Reject unsupported ABI/opcode/reserved bits and stale generations.
  • Check nonzero length/cookie, bounds, aliasing and exclusive ownership.
  • Check queue limits before pinning buffers or reserving the command.
  • A rejection must leave the resource ledger unchanged.

Exact values and numerical oracles

The byte copy/add-one ABI has exact output semantics. Floating-point inference requires a separate dtype/error/quality contract.

A high-precision CPU reference is not a universal bit-exact oracle for optimized GPU math.
