Lowering: a model becomes an artifact

Graph → partition/fuse → library or generated kernels → runtime artifact.

  • Choose layouts, memory plans and execution order.
  • Use a library or specialized code generator where supported.
  • Provide a legal path for every remaining operator.

IREE: one compiler, many HAL targets

IREE lowers a model for a selected target and packages a runtime artifact.

  • Match compiler target, runtime device and ABI.
  • Include allocation, transfer and synchronization support.
  • A successful compile is followed by load, execute and output checks.

TVM: Relax, TensorIR and BYOC

TVM can partition matched subgraphs for external code generation (BYOC).

  • Graph patterns identify the supported region.
  • Other operators still need legal lowering or an explicit fallback.
  • Measure boundaries, transfers and fallback cost in the whole model.

OpenXLA: plugin and compiler responsibilities

PJRT defines a device integration contract for compilation, buffers and execution.

  • A plugin connects a framework to the device implementation.
  • A compatible compiler must still lower the incoming program.
  • Test compilation, transfer, execution and numerical behavior together.

A new chip: the order of work

  • Bring up buffers, queues and a trivial operation.
  • Validate an anchor kernel and a complete model.
  • Expand coverage and tune from a measured operator-time split.

Exit evidence: correct output, known fallback and end-to-end timing.
