无锁的并行

  • 一次启动就是很多线程块。一次内核启动是由相互独立的线程块组成的网格；硬件在资源空出时把它们放到 N 个 SM 上。线程块之间互不等待，因此它们之间不需要锁。
  • 线程块内部，顺序来自屏障。生产者发出“分块就绪”，消费者发出“缓冲区空闲”（见“流水线冒险”）。这是握手，不是锁。
  • 线程块之间，顺序来自任务分解。Stream-K 只有在修正自己拆分的分块时才等待每个分块的标志；MPK 等待由依赖任务递增的事件计数器。
  • 减少启动的代价：持久化内核或巨型内核在整个生命周期内占着寄存器和共享内存，一个慢任务就可能让它所在的 SM 空闲。

已报告的结果：在 32,824 个 A100 GEMM 形状中的部分形状上，Stream-K 比 cuBLAS 快至多 6.7×；与逐算子启动内核的 vLLM 和 SGLang 相比，MPK 把端到端延迟降低至多 1.7×。两者都是研究或库的测量结果，不是本课程的测量。

空间型芯片让流水线显式化

在 Tenstorrent 的 Tensix 核上，流水线是每个核上的三个程序：

读取器（NoC 0 → SRAM）→ 环形缓冲区 → 计算（矩阵与向量单元）→ 环形缓冲区 → 写出器（SRAM → NoC 1）

  • 核内 1.5 MB SRAM 中的环形缓冲区就是生产者/消费者队列：每个内核在其数据或空间就绪时才继续。
  • 各个核通过二维环面片上网络相互传递数据，因此编译器或内核作者还要选择哪个核给哪个核供数。

思路与 GPU 上的 warp 特化相同，但角色是独立的处理器，队列在程序中是可见的。
