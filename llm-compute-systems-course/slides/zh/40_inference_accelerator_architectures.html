专用推理设计的优势条件

  • 规则张量计算可摊薄控制开销，并使操作数靠近计算单元。
  • SIMT 支持灵活的逐线程行为；调度、寄存器状态与缓存既有成本也有收益。
  • 现代 GPU 同时具有 SIMT 与 Tensor Core，不能把 GPU 与张量硬件简单对立。
Jouppi et al., ISCA 2017 · CUDA SIMT guide · CUDA tile guide

推理改变优化目标

  • 服务需要处理重复请求、延迟约束，以及长期驻留的模型与 KV 状态。
  • Prefill 提供较大矩阵计算；小批量 decode 可能受权重带宽与阵列填充不足限制。
  • 推理需求推动专用设计；训练与后训练仍然重要，Ironwood 也支持两者。

成本、供给与软件投入

在固定质量与延迟目标下，评估每个有效输出 token 的成本。

  • 计入利用率、能耗、内存容量、网络，以及迁移和运维投入。
  • 供给与出口限制会改变采购选择；BIS 于 2025 年 1 月收紧先进芯片管制。
  • 本地供给是战略动因，不能作为某款芯片更快的证据。

INT8、FP8 与 INT4 的不同约束

格式潜在收益协同设计要求
INT8更小的操作数缩放、累加精度与校准
FP8紧凑浮点数格式支持、缩放与质量检验
INT4 权重减少权重流量打包、缩放及反量化路径

仅权重 INT4 不代表激活或所有运算都是 INT4；支持范围取决于芯片、算子与后端。
