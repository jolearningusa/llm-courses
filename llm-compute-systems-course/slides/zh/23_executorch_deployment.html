DSP 和 NPU 目标自带编译器

  • Qualcomm：Qualcomm AI Engine Direct（QNN）划分器把受支持的子图交给 HTP（Hexagon）或 GPU 后端。下沉需要主机上安装 Qualcomm SDK，自定义算子以 C++ HTP op package 实现。
  • Cadence HiFi、Fusion 和 Vision：没有委托。自定义算子和编译器 pass 调用 8 位量化的 NNLIB 内核，运行时用 Xtensa 工具链构建。
  • 两者都不使用 Triton。内核来自厂商库，厂商 SDK 是构建约定的一部分。
