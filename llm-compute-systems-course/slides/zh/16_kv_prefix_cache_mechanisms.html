块示例算例

块大小为 4；token 为 [0…8]。热匹配可以复用两个完整的块（八个 token）；在我们的教学模型中，最后那个不完整的 token 需要重计算。

改变 token 0 会破坏连续匹配；改变 token 4 只保留第一个块。
