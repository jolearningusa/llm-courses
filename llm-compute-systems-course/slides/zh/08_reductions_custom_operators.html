RMSNorm

yᵢ = xᵢ wᵢ / √(mean(x²) + ε)

对一行做一次归约，再缩放每个元素。示例使用连续存储的 float32 输入/权重；其他 dtype 和步幅需要显式支持。

归约顺序与舍入

浮点加法不满足结合律。并行树可能与串行参考结果不同；声明合适的误差容差，检查困难输入，而不是要求比特完全一致。

稳定的 softmax

m = max(x); pᵢ = exp(xᵢ − m) / Σexp(xⱼ − m)

减去行最大值可以避免指数运算中不必要的溢出。显式检查归一化以及掩码/全无效时的行为。

优化顺序

Correct baseline → coalescing → reduction layout → fusion → shape tuning

一次只改变一种机制。修改实现时保留参考结果和反例。

7 / 17

Warp 级归约

warp 内的方法可能减少共享内存/屏障流量。检查活跃掩码、尾部 lane 和支持的执行宽度。不要用 warp 原语替代必需的块级通信。

融合的权衡

合并操作可以减少流量和启动，但会增加存活状态，并可能限制可用的并行度。把融合路径与实际的分离基线进行比较。

反向是另一份工作

只有前向的 CUDA 实现还不是训练算子。实现或注册反向，然后把输入梯度和参数梯度与即时模式的参考结果比较。

编译器集成

Operator schema → metadata / fake execution → backend kernel → autograd

即时调用成功并不能证明导出、编译或多形状行为正确。测试每条需要的路径。
