组大小在误差与元数据之间权衡

Weights → groups → scale per group → quantized codes → packed bytes

更小的组可以隔离离群值，但会增加缩放因子、填充和转换工作。

字节预算算例

1,024 个权重，int4，组大小 32，FP32 缩放因子，无零点：

512 payload + 32 × 4 scales = 640 B

相对 2,048 B 的 BF16：原始数组缩小 3.2×，不含张量头、对齐和工作区。

Read packed weights → unpack / scale → compute → write output

舍入与归约顺序

有限精度改变了结合律。即使没有量化，并行归约、融合操作和不同的累加器也会改变结果。设定有依据的绝对容差和相对容差。

不利的形状

  • 工作量太少、不足以摊销分发开销的小矩阵。
  • 会触发填充或回退的不受支持的维度。
  • 权重更新后频繁地重新打包。
  • 离群值很多的组和异常大的激活。
