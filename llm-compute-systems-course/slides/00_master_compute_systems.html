The execution stack

PyTorch → compiler → kernels → runtime / OS → hardware → network

The same operation can be limited at different layers. Name the limiting resource before selecting a tool.

Where the work runs

Choose the layer from evidence: faster kernels cannot remove an exposed host or network wait.

3 / 15

Training work

Forward → saved activations → backward → gradients → optimizer

Track useful tokens, numerical behavior, memory, collective waits and recoverable state.

4 / 15

Inference work

Prefill → decode → queue / tool wait → resume

Track completed requests, accepted tokens, latency targets and state retained between calls.

A bounded workload primer

Model design is background; efficient execution is the subject.
