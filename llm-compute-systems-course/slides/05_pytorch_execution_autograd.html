Views and copies

A view may share underlying storage while changing shape/stride. A contiguous conversion can allocate and copy. Account for those costs when comparing a layout-specific fast path.

4 / 16

Worked layout example

x: shape (4, 8), contiguous strides (8, 1)
x.T: shape (8, 4), strides (1, 8)

The transpose can describe the same storage. A consumer requiring another layout may introduce work; inspect instead of assuming zero total cost.

5 / 16

Autograd records dependencies

Forward operations → saved state → backward operations → gradients

Forward intermediates may outlive their immediate consumer. These lifetimes contribute to peak memory.

6 / 16

A linear layer backward

Y = XWᵀ; dX = dY W; dW = dYᵀ X

Forward speed alone omits two major backward computations. Bias and nonlinear layers add their own work/state.

Saved tensor inspection

Use the eager saved-tensor hook interface to log shape, dtype and logical bytes for a small example. A list of saved tensors is not an allocator peak: aliases and duplicated references require care.

8 / 16

Gradient accumulation

Repeated backward calls can accumulate parameter gradients. Clear them at the intended boundary, and preserve effective-batch semantics when comparing implementations.

9 / 16

Optimizer scope

Forward → loss → backward → optimizer update

Specify whether a benchmark includes every stage. The L2 core experiment times forward and backward; optimizer work is not silently included.

10 / 16

Correctness contracts

  • Same initial weights, inputs, loss and mode.
  • Compare outputs and parameter/input gradients.
  • Declare dtype and tolerance; preserve mutation and aliasing behavior.
11 / 16

Training and inference modes

Evaluation mode controls module behavior; disabling gradient recording controls autograd work. These are separate choices. Use the same intended mode in the baseline and intervention.

12 / 16

Custom operator responsibilities

Declare shape/dtype behavior, mutation/aliasing and gradient support. A compiled forward implementation does not automatically supply a correct backward or metadata contract.
