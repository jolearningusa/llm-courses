In eager mode most operators launch one kernel. Views launch none, and some operators launch several kernels or call a library. Compilers change this mapping (deck 06).

Correctness contracts

  • Same initial weights, inputs, loss and mode.
  • Compare outputs and parameter/input gradients.
  • Declare dtype and tolerance; preserve mutation and aliasing behavior.
13 / 18

Training and inference modes

Evaluation mode controls module behavior; disabling gradient recording controls autograd work. These are separate choices. Use the same intended mode in the baseline and intervention.
