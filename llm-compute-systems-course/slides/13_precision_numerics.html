Packing is observable

Two 4-bit codes share a byte. Define signed encoding, nibble order, odd-tail padding and original length. An integer tensor with values −7…7 is not automatically packed int4 storage.

A local error bound

|x − sq| ≤ s/2

For finite inputs without clipping beyond a scale’s chosen range, nearest rounding bounds scalar reconstruction error. It does not bound an entire model’s task quality.

11 / 17

Conversion can dominate

Read packed weights → unpack / scale → compute → write output

Measure the whole path. A float matrix multiplication after Python dequantization does not establish low-bit acceleration.

12 / 17

Rounding and reduction order

Finite precision changes associativity. Parallel reductions, fused operations and different accumulators can change results even without quantization. Set justified absolute and relative tolerances.

13 / 17

Adverse shapes

  • Tiny matrices with little work to amortize dispatch.
  • Unsupported dimensions that trigger padding or fallback.
  • Frequent repacking after weight updates.
  • Outlier-heavy groups and unusually large activations.
