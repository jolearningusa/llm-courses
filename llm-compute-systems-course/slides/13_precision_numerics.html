2 / 16

Range and resolution

Exponent bits affect range; significand bits affect relative spacing. Integer formats instead depend on scales and zero points. Equal bit width does not imply equal error or identical hardware support.

3 / 16

A symmetric teaching quantizer

s = max|x| / qmax; q = round(x/s)

Use qmax=7 for our signed int4 example, 127 for int8. Reserve unused codes and explicitly define the all-zero group. This is not a vendor packing format.

4 / 16

Group size trades error for metadata

Weights → groups → scale per group → quantized codes → packed bytes

Smaller groups can isolate outliers but increase scales, padding and conversion work.

5 / 16

Worked byte budget

1,024 weights, int4, group size 32, FP32 scales, no zero points:

512 payload + 32 × 4 scales = 640 B

Against 2,048 B of BF16: 3.2× raw-array reduction, excluding tensor headers, alignment and workspace.

6 / 16

Packing is observable

Two 4-bit codes share a byte. Define signed encoding, nibble order, odd-tail padding and original length. An integer tensor with values −7…7 is not automatically packed int4 storage.

7 / 16

A local error bound

|x − sq| ≤ s/2

For finite inputs without clipping beyond a scale’s chosen range, nearest rounding bounds scalar reconstruction error. It does not bound an entire model’s task quality.

8 / 16

Outlier exercise

Compare [0.01, −0.02, 0.03, 20] under one scale and separate groups. Explain why a single large value can erase small values, and what extra metadata buys.

9 / 16

Activation error amplifies differently

ΔY = X ΔW + ΔX W + ΔX ΔW

Weight reconstruction error alone misses the workload’s activation distribution. Use held-out inputs and task-level acceptance criteria.

10 / 16

Conversion can dominate

Read packed weights → unpack / scale → compute → write output

Measure the whole path. A float matrix multiplication after Python dequantization does not establish low-bit acceleration.

11 / 16

Rounding and reduction order

Finite precision changes associativity. Parallel reductions, fused operations and different accumulators can change results even without quantization. Set justified absolute and relative tolerances.

12 / 16

Adverse shapes

  • Tiny matrices with little work to amortize dispatch.
  • Unsupported dimensions that trigger padding or fallback.
  • Frequent repacking after weight updates.
  • Outlier-heavy groups and unusually large activations.
13 / 16

L6A: inspect the actual bytes

The standard-library reference packs symmetric int4 and int8, stores FP32 scales and handles uneven groups. Validate reconstruction, tails and invalid inputs before comparing bytes.

14 / 16

L6B: evaluate a precision recipe

Use CPU BF16 autocast in the pinned PyTorch environment for a small training comparison. Record loss and gradient differences; it is a numerical experiment rather than an LLM quality evaluation.
