A ring teaching model

T ≈ 2(p−1)α + 2(p−1)N/(pβ)

p ranks, N input bytes/rank, α latency/step, β effective link bytes/s. Homogeneous ring estimate; excludes topology contention and protocol effects.

Diagnose a late bucket

Check gradient readiness, rank skew, network contention and launch delay. Increasing bandwidth will not fix a rank that reaches the collective late.

12 / 16

An adverse case

An injected slow rank delays collective completion on all ranks. Use maximum rank step time, not the fastest rank’s local compute time, to report synchronous throughput.

L7B: controlled skew
