(g₀ + g₁)/2 = g_global

Peak is not persistent state

A rank can temporarily hold gathered parameters, activations, gradient buckets and prefetched next-layer buffers simultaneously. The lowest persistent estimate may still run out of memory.

14 / 22

Wrapping boundaries matter

Small groups increase launch/collective overhead; large groups increase transient residency and may reduce overlap opportunities. Choose boundaries from memory and timeline evidence.

15 / 22

Gradient accumulation

Synchronizing every microbatch can waste communication. Deferred synchronization needs correct loss scaling and enough memory for retained gradients; implementation details differ between DDP and sharded training.

16 / 22

Initialization and reproducibility

  • Same initial parameters, optimizer and data coverage.
  • Control random seeds and stochastic layers.
  • Record sampling, dropped/padded examples and token weighting.
  • Compare update tensors before interpreting throughput.
17 / 22

Failure modes

A missing rank, inconsistent collective order or uneven loop termination can hang the job. Fail with diagnostics and timeouts; do not mask a protocol error with a larger timeout.

18 / 22

CPU evidence has a boundary

Our two-process Gloo path tests DDP update semantics. It does not validate NCCL/RCCL GPU overlap, FSDP memory savings or multi-node fabric performance.
