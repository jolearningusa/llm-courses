Near zero, relative error alone is insufficient. Freeze tolerances before candidate search.

Ask students to choose an oracle for a fused reduction versus an integer descriptor. A typical finite-value rule is abs(candidate-reference) ≤ atol + rtol × abs(reference); choose bounds per operation and dtype, not one universal constant. Include cancellation, large dynamic range, tails and nonfinite inputs when supported. A higher-precision CPU calculation helps estimate error but is not automatically an exact specification. Low-bit format names alone do not define accumulation, scaling or task-quality acceptance. ULP is useful only with an explicitly comparable format and exceptional-value policy.

Concurrency needs explicit invariants

  • No buffer reclaimed while device work may access it.
  • No completion published before output visibility.
  • No stale completion accepted after a generation-changing reset.
  • Queued cancellation and in-flight abort have different contracts.

Fault injection and formal reasoning

Inject allocation failure, delayed completion, missing interrupt or reset at a declared boundary. Check cleanup, progress and recoverability.

Use a small state model to examine orderings and invariants. A bounded model result is not proof of arbitrary hardware behavior.

Retain buffers until completion or target-supported quiescence establishes safety.

Predict: submit → DMA starts → IRQ lost → host times out → free buffer. Which step violates ownership?

FaultSafety / progress obligation
Lost interruptRetain buffers; poll completion or enter supported recovery
Reset during transferProve quiescence before reclaiming; reject stale completions
Delayed completionMeet a declared progress bound, or report a recoverable failure

The invalid step is freeing memory while DMA may still access it. An interrupt is a notification, not the transfer itself. Distinguish safety (no use-after-free or stale completion) from liveness (eventual completion or bounded recovery under declared assumptions). Replay delay/IRQ/reset combinations with recorded seeds and minimize an event trace. Enumerate a small state model to look for forbidden transitions; report its depth, fairness assumptions and abstraction. Linux DMA mapping and memory-order rules are target contracts, not automatically implemented by the CPU trace lab. Formal proof applies to the model and assumptions, not arbitrary silicon.

Physical evidence needs the right target

Simulation checks modeled behavior. FPGA prototypes and functional emulators do not reproduce the final silicon’s physical PVT behavior.

On a test board, record power/temperature/clocks, operating conditions and recovery. PVT means process, voltage and temperature.
