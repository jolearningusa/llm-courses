Producer API at the pinned release

ep = torch.export.export(model, (x,))
torch._inductor.aoti_compile_and_package(
    ep, package_path="model.pt2")

The 2.9 API is prototype/private-named, and the PyTorch 2.14 documentation still places it under torch._inductor. Pin and revalidate rather than assuming stable compatibility.
