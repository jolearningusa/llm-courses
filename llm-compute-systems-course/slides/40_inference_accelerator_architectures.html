Where specialized inference designs can win

  • Regular tensor work can amortize control and keep operands near arithmetic units.
  • SIMT supports flexible per-thread behavior; scheduling, register state and caches have costs and benefits.
  • Modern GPUs combine SIMT with Tensor Cores. “GPU versus tensor hardware” is a false binary.
Jouppi et al., ISCA 2017 · CUDA SIMT guide · CUDA tile guide

Inference changes the optimization objective

  • Serving adds repeated requests, latency constraints and long-lived model/KV state.
  • Prefill offers larger matrix work; small-batch decode may expose weight bandwidth and underfill arrays.
  • Inference demand motivates specialization; training and post-training still matter. Ironwood supports both.
Google inference positioning · Google TPU7x specifications · Evidence review and reading map

Cost, availability and the software bill

Evaluate cost per accepted output token at a fixed quality and latency target.

  • Include utilization, energy, memory capacity, networking and porting/operations effort.
  • Supply and export restrictions can change procurement choices; BIS tightened advanced-chip controls in January 2025.
  • Domestic supply is a strategic driver, not evidence that one chip is faster.
BIS, 2025-01-15 · Alibaba full-stack keynote

INT8, FP8 and INT4 are different contracts

FormatPotential benefitCo-design requirement
INT8Smaller operandsScales, accumulation, calibration
FP8Compact floating pointSupported format, scaling and quality checks
INT4 weightsLower weight trafficPacking, scales and dequantization path

Weight-only INT4 does not imply INT4 activations or all-INT4 arithmetic. Support depends on chip, operator and backend.

A systolic PE grid

A processing element (PE) multiplies operands and updates a partial sum. Neighbor links move data in a regular rhythm.

For C = A × B, reuse a tile inside the array instead of fetching each operand again for every multiply.
