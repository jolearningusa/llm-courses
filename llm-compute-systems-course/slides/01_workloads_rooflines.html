A minimal traffic model

B = bytes/element × (MK + KN + MN)

One read of each input and one output write. This is an idealized baseline: caches, repeated loads, output accumulation and intermediates change actual traffic.

A roofline lower bound

t ≥ max(F / C, B / W)

C is an applicable compute rate; W is bandwidth for the same scope. Perfect overlap gives a lower bound, not a complete runtime predictor.

Capacity is a separate constraint

live bytes + workspace + headroom ≤ usable memory

A bandwidth-efficient kernel may still fail to fit. Logical tensor bytes, allocated bytes and allocator-reserved bytes are different measurements.

13 / 20

Ask whether passing the bandwidth budget guarantees that the model fits. Add workspace and headroom to live tensor bytes before comparing usable memory. Reserved allocator bytes are an accounting quantity, not simply another tensor to add twice.

Communication and dependencies

Compute phase → collective / transfer → dependent phase

Use payload and effective link rate for a transfer bound; add latency and contention. Sequential phases cannot all be hidden by taking one global maximum.

15 / 20

Draw a compute phase followed by a required transfer and another compute phase. Add durations for genuinely serial phases; do not take one maximum across the entire job. Payload over effective bandwidth omits startup, contention and synchronization.

Amdahl’s limit

speedup = 1 / ((1 − f) + f / s)

If a kernel occupies 20% of runtime and becomes twice as fast, total speedup is about 1.11×. Measure the time fraction in the actual workload.

16 / 20

Substitute f=0.2 and s=2 into 1/(0.8+0.1), giving about 1.11. Even an infinitely fast target kernel gives only 1/0.8=1.25 in this fixed decomposition. Ask why changing overlap can invalidate the original time fraction.

An experiment that can disprove the prediction

  • Hold semantics and workload fixed; vary M or batch size.
  • Record wall time, device time and traffic evidence separately.
  • Compare predicted transition with measured behavior; explain any gap.
