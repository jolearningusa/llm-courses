Memory ownership

Keep source buffers valid until asynchronous transfers finish. Do not overwrite a staging buffer merely because the enqueue call returned. A faster pipeline that races its inputs is incorrect.

11 / 20

Use a two-buffer staging example and mark when each slot becomes reusable. Reuse after enqueue can corrupt an input still being read. State the completion event or ownership transfer that makes the reuse legal.

Virtual memory and faults

Shared addressability, coherent access and high bandwidth are different properties. Faults and migration can change the observed data path.

Linux HMM
12 / 20

Separate one address space from where data resides and how it moves. A valid pointer does not promise local HBM bandwidth. Fault and migration evidence is needed before blaming a kernel for a delayed access.

Allocator behavior

Repeated allocation can introduce overhead and change peaks. Reuse buffers where semantics permit, and compare both steady reuse and a realistic allocation-inclusive workload.

13 / 20

Compare a reused buffer loop with an allocation-inclusive path. Both are useful experiments when their boundaries are named. Reuse must preserve lifetimes and cannot silently remove production work from the comparison.

14 / 20

A queue can hide preparation jitter until it drains. More prefetch increases memory use; an unbounded producer can consume resources without raising throughput.

Measure queue occupancy and memory alongside the achieved rate.

Draw queue occupancy rising when the producer is faster than the consumer. More buffering can absorb jitter but cannot improve a permanently slower stage. Ask students to measure memory and backpressure as well as rate.
