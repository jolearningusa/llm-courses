# Mechanism figures: sources and reading guide

## Attribution and source boundaries

The new graphics are original schematics informed by primary-source diagrams, algorithms and documentation. They are not traced copies, redistributed upstream artwork, measured traces, die layouts or vendor endorsements. Original SVGs follow the course license. ## Reading conventions

- Arrows encode the labeled dependency, transfer, selection or state transition. Schematic schedules do not encode milliseconds. Equal-width ledger boxes name terms, not measured proportions. An intersection symbol marks joint constraints.
- Small head/rank/lane/block examples are constructed teaching subsets, not hardware-width claims. The 3×5-in-4×6 occupancy diagram is a shape example, not a utilization benchmark.
- KV capacity, prefix identity, task-answer freshness and in-flight ownership have separate contracts. A matching suffix or host timeout is insufficient for reuse.
- Sharding, prefetch, checkpointing and recomputation change lifetimes. Peak memory and durable recovery require their own evidence.
- Existing hardware specification tables and pinned APIs remain in place. Newly inspected documentation supports concepts and does not silently change laboratory dependencies.
