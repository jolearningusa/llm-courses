Convolutions and LeNet

LeCun et al., 1989 and 1998. An image has strong local structure and the same pattern can appear anywhere. Convolutional layers build that knowledge into the network: small filters, shared across all positions. LeNet-5 read handwritten digits on bank cheques with about 60,000 parameters.

Problem: MLPs ignore the structure of images

  • A fully connected layer on a 224 × 224 × 3 image has 150,528 inputs per hidden unit. A thousand units already need 150 million weights.
  • It treats pixel (3, 5) and pixel (200, 17) as unrelated features, and an edge learned in one corner must be learned again in every other place.
  • In lab L4 an MLP trained on shapes in the left of a 12 × 12 image classifies them at 72% there, and at 28% (chance is 25%) when the same shapes move right.
  • What we want: local connections (nearby pixels matter together) and shared weights (the same detector everywhere).

The convolution

With Cin input channels and Cout filters of size k × k, a layer has Cout·Cin·k² weights, independent of the image size. Stride s skips positions; padding p adds a border so the output can keep the input's size.

Three properties

  • Sparse interactions: each output depends on a k × k patch. Stacking layers grows the receptive field: three 3 × 3 layers see 7 × 7 input pixels.
  • Parameter sharing: one filter is applied everywhere, so a layer's size does not grow with the image, and what is learned in one place is used in all.
  • Translation equivariance: shift the input and the output shifts the same way. Lab L4 checks this exactly.
  • These are assumptions about the data. They are right for images, audio spectrograms and other grid data, and they are why convolutional networks need far less data than MLPs for the same accuracy.

Pooling

  • Max pooling replaces each 2 × 2 window by its maximum, halving the width and height. The gradient flows only to the maximal input of each window.
  • It makes the representation approximately invariant to small shifts, and cuts computation in later layers.
  • LeNet-5 used trainable average pooling ("subsampling"); later networks mostly used max pooling, or strided convolutions instead.
  • Global average pooling averages each channel over the whole image, turning a feature map into a vector for the classifier whatever the input size. The lab's CNN ends this way.

LeNet-5

Convolutions extract local features; subsampling reduces resolution; the last layers classify. Squashing (scaled tanh) nonlinearities throughout. LeNet-5 reached 0.95% test error on MNIST, and 0.8% when trained on artificially distorted images (deck 10's augmentation).

The 1989 and 1998 papers

  • 1989: LeCun et al. trained a network with shared-weight, locally connected layers end to end by backpropagation on US Postal Service zip-code digits. Constraining the architecture was the point: it reduced the number of free parameters and improved generalization.
  • 1998: "Gradient-based learning applied to document recognition" compared many classifiers on MNIST (a dataset it introduced) and built a full cheque-reading system around LeNet-5, deployed commercially.
  • Then a long pause: without much more data and compute, CNNs did not beat other methods on natural images until 2012 (deck 13).

Where this shows up in LLMs

  • Parameter sharing across positions is also what a Transformer does: the same attention and feed-forward weights are applied to every token.
  • The Vision Transformer cuts an image into 16 × 16 patches with what is exactly a strided convolution, then drops the locality assumption and lets attention learn it from data (Transformer course deck 34).
  • Speech models such as Whisper start with convolutional layers over the audio spectrogram before the Transformer (deck 40), and Mamba-style models use a short causal convolution in each block (deck 23).
  • The trade-off taught here recurs: built-in assumptions need less data; learned structure wins when data is plentiful.
