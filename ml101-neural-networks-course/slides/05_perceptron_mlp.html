From the perceptron to the multilayer perceptron

A single linear unit draws one straight boundary. Stack units with a nonlinearity between them and the network can represent almost any function. This deck builds the multilayer perceptron (MLP), the network every later architecture extends.

The perceptron (1958)

  • Rosenblatt's perceptron outputs 1 if wᵀx + b > 0 and 0 otherwise: a linear classifier with a hard threshold.
  • Learning rule: on each mistake, move w toward the misclassified input (w ← w + x for a missed positive, w − x for a missed negative). On correct predictions, do nothing.
  • If the classes are linearly separable, the rule finds a separating hyperplane in a finite number of mistakes. If they are not, it never settles.
  • The threshold has zero gradient almost everywhere, so the rule cannot be extended to several layers. Smooth activations fix that (slide 5).
Rosenblatt 1958, doi:10.1037/h0042519 · bibliography

The limit: XOR

  • XOR labels (0,0) and (1,1) as 0, and (0,1) and (1,0) as 1. No straight line separates the two classes, so no linear model, perceptron or logistic regression, can get all four right.
  • Minsky and Papert's 1969 book Perceptrons analyzed such limits of single-layer networks, and interest in neural networks fell for over a decade.
  • A hidden layer removes the limit: it maps the inputs into a space where the classes are separable. In lab L1, a linear model gets 2 of 4 XOR points right; a network with one hidden layer of 8 tanh units gets all 4.

The multilayer perceptron

Each layer is a linear map followed by an elementwise nonlinearity φ; the last layer is linear and feeds softmax (deck 02). Without φ, W₃W₂W₁ is a single matrix and the whole network collapses to one linear model.

4 / 10

Activation functions

  • Sigmoid and tanh saturate: for large |z| the derivative is near 0 and almost no gradient flows back (deck 07). tanh is zero-centered, which helps the next layer.
  • ReLU max(0, z) has derivative 1 for every positive input, so it does not saturate there, and it is cheap. Glorot, Bordes and Bengio showed deep rectifier networks training well without unsupervised pre-training. A unit whose input stays negative gets no gradient and can "die".
Glorot, Bordes and Bengio 2011, AISTATS · Goodfellow, Bengio and Courville, Deep Learning, §6.3 · bibliography

What one hidden layer can represent

  • Universal approximation: Cybenko proved that sums of sigmoidal units, Σj aj σ(wjᵀx + bj), can approximate any continuous function on a bounded region as closely as you like, given enough units. Hornik, Stinchcombe and White showed the same for other activations in the same year.
  • The theorem is about existence. It does not say how many units are needed (possibly exponentially many), or that gradient descent will find the weights, or that the result generalizes.
  • Depth helps in practice: deep networks build features from features and often need far fewer units than a shallow one for the same function.
Cybenko 1989, doi:10.1007/BF02551274 · Goodfellow, Bengio and Courville, Deep Learning, §6.4.1 · bibliography

Training an MLP

  • The recipe is unchanged from deck 02: logits from the network, softmax cross-entropy loss, mini-batch SGD (deck 03).
  • The loss is no longer convex in the weights. Two networks with permuted hidden units compute the same function, so there are always many equivalent minima.
  • The one new requirement is the gradient with respect to every weight in every layer, efficiently. That is backpropagation, deck 06.
  • Then two practical questions: where to start the weights (deck 07) and how to step (deck 08).

Where this shows up in LLMs

  • Every Transformer block contains an MLP, the feed-forward network (FFN), applied to each token separately: d → 4d → d with a nonlinearity in between. In the 2017 Transformer, d = 512 and the inner size is 2048.
  • The FFN holds about two thirds of a block's weights (8d² against 4d² for attention), so it is where most of an LLM's parameters live.
  • ReLU in 2017 gave way to GELU and then gated units such as SwiGLU (Transformer course deck 18); mixture-of-experts layers replace one FFN by many (decks 19 to 22).
Vaswani et al. 2017, arXiv:1706.03762, §3.3 · Transformer course, decks 18 to 22 · bibliography
