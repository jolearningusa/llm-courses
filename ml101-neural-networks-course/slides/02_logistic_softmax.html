Logistic regression and softmax

Classification with a linear model: turn a score into a probability, and train by making the observed labels likely. The softmax and cross-entropy loss introduced here are, unchanged, the output layer and training loss of every language model.

Why not regress on the labels?

  • Code the classes as y ∈ {0, 1} and fit least squares: the predictions are not probabilities, they run below 0 and above 1.
  • Points far on the correct side of the boundary still have large squared errors, so they drag the boundary toward themselves and can flip correct predictions.
  • What we want instead: a model of P(y = 1 | x), and a loss that charges for being confidently wrong, not for being confidently right.

The sigmoid turns a score into a probability

P(y = 1 | x) = σ(wᵀx + b). Inverting, wᵀx + b = log(p / (1 − p)): the linear score is the log-odds. The decision boundary p = 0.5 is the hyperplane wᵀx + b = 0.

The loss comes from the likelihood

L(w) = −(1/n) Σ [ yi log pi + (1 − yi) log(1 − pi) ]

  • Each label is a coin flip with probability pi = σ(wᵀxi). The negative log-likelihood of the data is the binary cross-entropy above.
  • Its gradient is (1/n) Xᵀ(p − y), the same shape as the least-squares gradient with p in place of Xw. The error signal is simply prediction minus target.
  • The loss is convex in w, so gradient descent finds the global minimum. There is no closed form; this is the first model we can only fit iteratively.

Softmax: k classes

z = Wᵀx + b , pc = ezc / Σj ezj

  • One score (a logit) per class; softmax exponentiates and normalizes so the k outputs are positive and sum to 1.
  • Adding the same constant to every logit changes nothing, so only differences between logits matter. With k = 2, softmax of (0, z) is σ(z): logistic regression is the two-class case.
  • Dividing the logits by a temperature T > 1 flattens the distribution and T < 1 sharpens it; sampling from a language model uses exactly this knob.

Cross-entropy and its gradient

L = −(1/n) Σi log pi, yi , ∂L/∂zi = (pi − onehot(yi)) / n

  • Only the probability of the correct class enters the loss, but the gradient pushes every logit: the correct one up by 1 − p, every other one down by its own probability.
  • Sanity check at initialization: with all logits equal, p = 1/k and the loss is log k. For 10 classes that is 2.303; for Llama 3's 128,256-token vocabulary it is 11.76. A first-step loss far from log k means a bug or a bad init.
  • The lab checks that a zero weight matrix gives exactly log k, and that the analytic gradient matches finite differences.

Computing it without overflow

def log_softmax(Z):
    Z = Z - Z.max(axis=1, keepdims=True)      # shift: same result, no overflow
    return Z - np.log(np.exp(Z).sum(axis=1, keepdims=True))

# -log sigmoid(z) = log(1 + e^-z) = np.logaddexp(0, -z)
  • e1000 overflows a float; after subtracting the row maximum the largest exponent is e0 = 1.
  • Compute log-probabilities directly instead of log(softmax(z)): a probability that rounds to 0 gives log 0 = −∞.
  • Frameworks fuse softmax and cross-entropy into one operation for the same reason (PyTorch cross_entropy takes logits, not probabilities).

A trap: perfectly separable data

  • If a hyperplane separates the classes perfectly, scaling w up makes every pi closer to its label and the loss closer to 0. The minimum is never reached; the weights grow without bound.
  • The boundary may still be good, but the probabilities become overconfident, which hurts on new points near the boundary.
  • Fixes: an L2 penalty (deck 01's ridge term, which makes the minimum finite), or stopping early. Large models trained on finite data meet the same problem; deck 10 returns to it.
  • In lab L0 the three blobs are almost separable: after 300 steps accuracy is 99.7% and the loss is 0.020, still falling.

Where this shows up in LLMs

  • A language model's last layer is softmax regression: a linear map from the final hidden state to one logit per vocabulary token, then softmax.
  • Its pre-training loss is the cross-entropy of the next token, averaged over every position. Perplexity is eloss.
  • Generation samples from the softmax, usually with a temperature; greedy decoding takes the argmax.
  • Classification fine-tuning (sentiment, labels) puts a small logistic or softmax regression head on top of a pre-trained model.
