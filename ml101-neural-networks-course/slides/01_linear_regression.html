Linear regression and least squares

The simplest model that learns from data: predict a number as a weighted sum of inputs, measure the error, and choose the weights that make it small. Every idea in this course, from the loss to the gradient to the validation set, appears here first in its plainest form.

The supervised learning setup

  • Data: n examples (xi, yi), each xi a vector of d features and yi a target number (a price, a temperature, a score).
  • Model: ŷ = wᵀx + b. The parameters are the weights w and the bias b.
  • Loss: one number that says how wrong the predictions are on the data.
  • Learning: choose the parameters that minimize the loss.

Bias trick: append a constant 1 to every x and b becomes one more weight. Stacking the examples as rows of a matrix X (n × (d+1)) turns all n predictions into one product: ŷ = Xw.

The loss: mean squared error

L(w) = (1/n) Σi (wᵀxi − yi)² = (1/n) ‖Xw − y‖²

  • Squaring makes every error positive and punishes large errors more than small ones; a single outlier can pull the fit a long way.
  • Why squares, in probability terms: assume y = wᵀx + ε with Gaussian noise ε ~ N(0, σ²). The log-likelihood of the data is −(1/2σ²) Σ (yi − wᵀxi)² plus a constant, so maximizing likelihood is minimizing squared error.
  • That link between a loss and a likelihood returns in deck 02: a different noise model gives a different loss.

Solving it exactly: the normal equations

The gradient is (2/n) Xᵀ(Xw − y). Setting it to zero gives a linear system with a unique solution whenever the columns of X are linearly independent. Solve the system; do not invert XᵀX.

Hastie, Tibshirani and Friedman, The Elements of Statistical Learning, §3.2, Figure 3.2 · bibliography

Solving it step by step: gradient descent

w ← w − η · (2/n) Xᵀ(Xw − y)

  • Start anywhere, compute the gradient, take a small step against it, repeat. The step size η is the learning rate.
  • For this loss the iteration converges when η is below 2 / λmax, where λmax is the largest eigenvalue of (2/n) XᵀX. Above it the weights oscillate and blow up (a lab L0 check).
  • Why bother when a closed form exists? A d × d solve costs about d³ operations and needs all the data at once. Gradient steps cost one pass over the data and work for any differentiable model, which is the whole point of deck 03.

Nonlinear inputs, linear model

  • Replace x by features φ(x): powers [1, x, x², …, xp], products of inputs, or any fixed functions. The prediction wᵀφ(x) can now be a curve, but it is still linear in w, so the same closed form and the same gradient apply.
  • The question becomes which features to use. Too few and the model cannot follow the data; too many and it follows the noise (deck 04).
  • A neural network (deck 05) learns φ instead of having it fixed by hand: the last layer is still linear regression or classification on the features below it.

Ridge regression: penalize large weights

L(w) = (1/n)‖Xw − y‖² + λ‖w‖² ⇒ (XᵀX + nλI) w = Xᵀy

  • Adding λ‖w‖² keeps the weights small. The system is solvable for any λ > 0, even when features are redundant or there are more features than examples.
  • The price is bias: the fit no longer passes as close to the training points. The gain is lower variance, which deck 04 measures.
  • In a Bayesian reading, ridge is the most probable w under a Gaussian prior on the weights. In neural networks the same penalty is called weight decay (deck 10).

Where this shows up in LLMs

  • Every layer of a Transformer starts with a linear map, y = Wx + b, computed for all tokens at once as a matrix product, just as ŷ = Xw computes all predictions here.
  • Mean squared error is the training loss of diffusion models, which predict the added noise (Transformer course deck 38).
  • The ridge penalty is the weight decay in AdamW, the optimizer of nearly every LLM (deck 08).
  • The habit of checking a learned answer against a known one, as the lab does with the closed form, is how you test training code at any scale.
